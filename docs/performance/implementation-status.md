## Verified measurements and checks

- Canonical relief serialization removes duplicate raster/placement data from project SVG without constructing per-glyph DOM; four fidelity tests and all three real-browser binary default tests pass after this change.
- Standalone fast-block binary demo: 4,313,645 text bytes → 1,691,428 binary bytes; exact text round-trip. The earlier deflate representation was 1,014,686 bytes; the default trades some compression ratio for faster saving.
- 20 codec tests plus five fast-block tests cover native typed encoding, typed boundaries, noncanonical numeric text, lazy independent access, Unicode, earlier deflate sections and corrupt/truncated files; fast blocks also verify overlapping matches, bounds and malformed lengths.
- Real-browser binary load preserves state/culture/biome cell arrays, burg identities/placement/state and settlement label text; undo is exact (7,462 packed fixture cells).
- Twelve sparse real-demo state-cell history edits retain 4,307,797 UTF-8 block-payload bytes versus 51,763,781 logical version bytes. Embedded SVG newlines stay inside the SVG section; a one-cell edit creates only one 128-cell block. These are serialized payload measurements, not JS heap/RSS claims.
- App pure unit suite: 249 tests in 32 files pass, including transformed-label mutation and loaded-relief fidelity coverage. Five history tests and six existing pure reliability tests pass; MCP and app TypeScript checks pass.
- Cross-process pool test proves shared Chromium PID, cookie isolation and one-client disconnect safety.
- Shared fixture: 26/26 bridge cases pass with one renderer; real edits, snapshot restore, undo/redo and clean Node/page resets pass. The final four-case fixture rerun passes with the latest codec/serializer: cold setup 3.66 seconds versus warm snapshot reset 0.70 seconds.
- Initial dense-layer 100K redraw regressed 25.6%; the gate rejected it. Later native-save failures and the first fast-codec 13/15 result are retained. The final schema 2 paired run passes all 15 unchanged local gates: 100K generation 6702.0 → 5926.6 ms, save 180.5 → 232.2 ms, load 2158.3 → 1950.2 ms, redraw 1164.9 → 790.6 ms and regrid 4115.5 → 2849.9 ms. Saving remains slower; its absolute overhead stays below 100 ms. The 10K load is 99.7 ms slower, only 0.3 ms below the failure limit, so no robust CI pass is claimed.
